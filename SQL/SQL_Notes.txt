SQL - Structure Query Language

🔹 What is SQL?

SQL (Structured Query Language) is a standard language used to store, retrieve, update, and manage data in a relational database.

👉 SQL works with data stored in tables (rows & columns).

🔹 Why Do We Use SQL?

To fetch data from databases

To insert, update, delete records

To create and manage tables

To control access to data

To analyze data efficiently

SQL is used in:

Web applications

Data analytics

Backend systems

Automation & reporting tools

🔹 What is a Database?

A database is an organized collection of data stored electronically.

Example:

Database: CompanyDB
Table: Employees

🔹 What is a Table?

A table stores data in rows and columns.

emp_id	name	role	salary
101	Hemant	Developer	50000

Row → Record

Column → Field

🔹 Types of SQL Commands
1️⃣ DDL (Data Definition Language)

Used to define database structure.

Command	Purpose
CREATE	Create table/database
ALTER	Modify table
DROP	Delete table
TRUNCATE	Remove all records

Example:

CREATE TABLE employees (
  emp_id INT,
  name VARCHAR(50),
  salary INT
);

2️⃣ DML (Data Manipulation Language)

Used to manage data.

Command	Purpose
INSERT	Add data
UPDATE	Modify data
DELETE	Remove data

Example:

INSERT INTO employees VALUES (101, 'Hemant', 50000);

3️⃣ DQL (Data Query Language)

Used to fetch data.

Command	Purpose
SELECT	Retrieve data

Example:

SELECT * FROM employees;

4️⃣ DCL (Data Control Language)

Used for permissions.

Command	Purpose
GRANT	Give access
REVOKE	Remove access
5️⃣ TCL (Transaction Control Language)

Used to manage transactions.

Command	Purpose
COMMIT	Save changes
ROLLBACK	Undo changes
SAVEPOINT	Mark a point
🔹 Basic SQL Keywords
Keyword	Description
SELECT	Choose columns
FROM	Table name
WHERE	Filter records
AND / OR	Conditions
ORDER BY	Sort data
DISTINCT	Remove duplicates
LIMIT	Restrict rows

Example:

SELECT name, salary
FROM employees
WHERE salary > 40000
ORDER BY salary DESC;

🔹 SQL is Case-Insensitive

These are same:

select * from employees;
SELECT * FROM employees;


(Best practice: use UPPERCASE keywords)
